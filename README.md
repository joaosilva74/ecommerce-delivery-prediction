# 🚚 Previsão de Entrega no Prazo

Projeto de ciência de dados para prever se um produto será entregue no prazo.

## Dataset
- 10.999 registros de uma empresa de e-commerce
- Variáveis: warehouse, modo de envio, avaliação do cliente, desconto, peso, etc.

## Modelos testados
| Modelo | Acurácia |
|---|---|
| Random Forest | 67% |
| Regressão Logística | 64% |

## Tecnologias
Python, Pandas, NumPy, Matplotlib, Scikit-learn
